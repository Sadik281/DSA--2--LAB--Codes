# Data Structure and Algorithms II Laboratory

This repository contains my solutions, lab exercises, assignments, and practice code for **CSE 2218 – Data Structure and Algorithms II Laboratory** at **United International University (UIU)**.

## 📖 Course Information

- **Course:** CSE 2218 – Data Structure and Algorithms II Laboratory
- **Department:** Computer Science and Engineering
- **University:** United International University (UIU)

## 📚 Topics Covered

This repository includes implementations and practice problems on:

- Recursive Functions Review
- C++ Standard Template Library (STL)
- Divide and Conquer
  - Max-Min Problem
  - Merge Sort
  - Quick Sort
  - Maximum Sum Subarray
- Greedy Algorithms
  - Activity Selection
  - Fractional Knapsack
  - Huffman Coding
- Dynamic Programming
  - Coin Change Problem
  - 0/1 Knapsack Problem
- Graph Algorithms
  - Disjoint Set Union (DSU)
  - Minimum Spanning Tree (Kruskal's Algorithm)
  - Minimum Spanning Tree (Prim's Algorithm)
  - Dijkstra's Algorithm
  - Bellman-Ford Algorithm
- Hashing
- String Matching
  - Rabin-Karp Algorithm
